Model dosyaları bu tarayıcının yerel alanında saklanır. Tarayıcı verileri temizlenirse silinir. Supertonic 3 ağırlıkları OpenRAIL-M lisanslıdır.

Turkish-TTS · Sunucu bağlantısı

Bu model tarayıcıya indirilmez. Seslendir düğmesine bastığınızda metin, belirlediğiniz GPU sunucusuna gönderilir. Yalnızca güvendiğiniz bir sunucuyu kullanın.

Uzak sunucular HTTPS gerektirir. Sunucu, CORS ile Söylet'in adresine izin vermelidir. API modelini kullanmak için sunucuda Turkish-TTS çalışıyor olmalıdır.
Gizlilik ve çevrimdışı kullanım

Piper ve Supertonic cihazınızda çalışır; bu modeller için sunucu veya API anahtarı gerekmez. Turkish-TTS API seçilirse metin seçtiğiniz sunucuya gönderilir.
